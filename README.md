MDC 注音輸入法

安裝(只需要做一次)

1.解壓縮這個 zip。

2.第一次打開不要直接雙擊——因為這個 App 沒有簽開發者憑證,macOS 會擋。在 Finder 對 App 按右鍵(或 Control+點擊)→「開啟」,跳出警告後選「開啟」。之後就 可以正常雙擊使用了。

3.打開後會自動同步安裝:偵測到還沒裝 Squirrel(輸入法引擎)的話,會跳出 macOS 的 密碼輸入框,輸入你的 Mac 登入密碼就會自動裝好,不需要額外操作。

4.同步完成後,打開「系統設定 > 鍵盤 > 輸入來源/輸入方式」,按左下角「+」,找到 「中文(繁體)- 鼠鬚管」加入。

5.登出目前帳號再重新登入(第一次加入輸入法,系統需要這一步才會生效)。#這不是重開機 點mac右上方的蘋果登出自己在重新輸入電腦密碼登入即可    （當然重開機也行就是會比較久而已）
